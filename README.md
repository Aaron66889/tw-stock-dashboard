# 台股戰情正式版 V11

這是目前完整可部署版本。

## 核心功能
- 加權指數首頁：現值、漲跌、開高低、距高點、漲幅保留率
- 盤中判讀：多方強勢 / 上漲降溫 / 先強後弱 / 今日偏弱
- 近 5 日與 20 日方向：中期趨勢不因單日行情亂翻
- 市場結構：漲跌家數、成交資訊、台積電同步性、三大法人
- 個人持股：0050 / 0056 / 00878 / 00919 的市值、未實現損益、今日價格影響與集中度提示
- 海外訊號：NASDAQ / SOX / TSM ADR
- 明日結論：偏多 / 中性 / 偏空、信心、訊號清單、下一個重要更新、開盤環境、整日環境
- 自動模式：盤前 / 盤中 / 收盤 / 夜間 / 週末
- PWA：部署 HTTPS 後可加入手機主畫面
- API timeout / retry / cache / health check
- 缺資料時降級，不把舊資料或其他商品冒充即時

## 台指夜盤
前後端契約已完成 `/api/night-future`。目前刻意回報「尚未接入」。
原因：沒有確認穩定、適合長期程式化使用的即時來源前，不應把抓網頁或其他期貨資料冒充正式夜盤。
一旦有合法穩定 feed，只需修改 server.js 的 `nightFuture()`，前端與明日模型不必重寫。

## 執行
Node.js 18+：
```bash
npm start
```
瀏覽器開啟：
`http://localhost:3000`

## 部署
專案附：
- `render.yaml`
- `Procfile`
- `/health`

可部署至支援 Node.js 18+ 與 HTTPS 的 Web App 平台。
部署後，iPhone Safari 可「加入主畫面」。

## 更新頻率
- TWSE MIS：10 秒
- 市場結構：60 秒（後端快取）
- 海外行情：60 秒（後端 45 秒快取）
- 歷史資料：30 分鐘後端快取
- 三大法人：盤後資料

## 重要限制
公開/免費資料端點可能改版、限流或延遲。若要把它當成長期每天使用的正式產品，下一個工程階段應改用具 SLA/授權的行情來源，並加入資料庫、歷史訊號回測與監控。
